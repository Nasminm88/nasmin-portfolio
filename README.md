# Nasmin M — Mechanical Engineering Portfolio

## Run locally

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Open Terminal in the project folder.
4. Run:
   npm install
   npm run dev
5. Open the localhost URL shown by Vite.

## Build for deployment

npm run build

The production files will be in `dist/`.

## Deploy to Netlify

You can either connect the GitHub repository to Netlify or drag the `dist` folder into Netlify's deploy area.

## Before publishing

Replace the placeholder LinkedIn and GitHub links in `src/main.jsx` with your actual profile URLs.
